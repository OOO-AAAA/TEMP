## Запуск сервера

Установите .NET 8 SDK и выполните в папке проекта:

```sh
dotnet run --urls http://127.0.0.1:5000
```

При первом запуске сервер создаст `data/shop.sqlite3` из SQL-файлов в папке `data`.
Каталог доступен по адресу <http://127.0.0.1:5000/api/catalog>.

`POST /api/orders` принимает JSON с именем, телефоном и товарами:

```json
{"customer":"Тест","contact":"+375 29 000 00 00","items":[{"id":2,"quantity":2}]}
```

Сервер возвращает номер заказа и сумму в копейках. Две пары гантелей стоят 158 BYN.
Для тестирования путь к отдельной базе можно задать через `TEMP_SHOP_DB`.
